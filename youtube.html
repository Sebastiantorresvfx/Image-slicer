Setup — GitHub token
Create the token at github.com → Settings → Developer settings → Fine-grained tokens:
· Repository access: Only select repositories → the workflow repo above
· Permissions → Actions: Read & write, Contents: Read & write

How it works / iPhone tips
· Each download runs as a GitHub Actions job in your private repo — expect ~1 min of spin-up before the real download starts.
· The video lands in Safari's download manager → Files ▸ Downloads.
· To move it into your camera roll: open it in Files, tap Share, then Save Video.
· Files are auto-deleted from GitHub after ~12 h.
· Add this page to your Home Screen for one-tap access.
